# 脚注跳转

在思源笔记中插入、预览和管理脚注：正文点击跳转，侧栏直接编辑脚注内容，查看被引段落，还能统一引用写法、切换文末格式和重新编号。

## 快速开始

![插入脚注的三个步骤：输入斜杠命令、创建正文引用与文末脚注、在侧栏填写内容](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/01-insert.png)

1. 启用插件，打开需要添加脚注的文档。
2. 在正文段落或标题中输入 `/`，搜索“脚注”“footnote”或“jz”，选择“插入脚注”。
3. 插件会在光标处插入显示为 `[编号]`（例如 `[1]`）的脚注块引，并在文末创建对应的空脚注。
4. 在自动选中的侧栏编辑区填写脚注内容，修改会自动保存到原文档。
5. 悬停正文引用可预览内容；文本标记可点击跳到定义，块引沿用思源原生交互。

已有脚注的文档可直接使用，无须重新插入。点击顶部脚注按钮，选择“打开脚注侧栏”，或从右侧停靠栏打开“脚注”面板。

## 支持哪些脚注写法

正文引用支持两种写法：

| 写法 | 如何使用 |
| --- | --- |
| 文本标记 `[^1]` | 直接在正文输入，插件提供上标显示、预览和点击跳转。 |
| 静态块引 `[1]` | 由“插入脚注”或格式转换生成，指向对应脚注，使用思源原生悬浮预览。 |

`[1]` 是块引用的显示文字，**只输入普通文本 `[1]` 不会创建脚注引用**。已有显示为 `[^1]` 的脚注块引仍可使用，也可通过“统一格式”改成 `[1]`。

脚注内容支持以下两种格式，正文引用写法与文末格式可以独立选择。

### 格式一：`[^编号]: 内容`

在正文写引用，在脚注定义段落开头写相同编号：

```markdown
这段文字需要补充说明 [^1]。
另一段文字也可以引用同一条脚注 [^1]。

## 脚注

[^1]: 这里是脚注内容，可以包含加粗、链接等格式。
```

### 格式二：文末有序列表

将脚注内容写在文档最后的有序列表中，引用编号对应列表实际显示的序号：

```markdown
第一处说明 [^1]，第二处说明 [^2]。

## 脚注

1. 第一条脚注内容。
2. 第二条脚注内容。
```

插件只将文档末尾的顶层有序列表识别为脚注区，末尾空段落不影响识别。列表后若还有其他正文，就不再是文末脚注列表；正文中的其他列表不会被当作脚注。列表可以从其他正整数开始，按实际序号匹配。

**同一文档请选择一种定义格式。** 文档中存在 `[^编号]: 内容` 时，插件优先使用这种格式；只有没有此类定义时，才读取文末有序列表。

## 插入和编辑脚注

### 斜杠菜单插入

在正文段落或标题中使用 `/` → “插入脚注”，即可同时创建正文引用和文末内容，并在侧栏选中新脚注。

- 已有文末有序列表脚注时，在列表末尾追加一项。
- 使用 `[^编号]: 内容` 时，在文末追加空定义；没有文末“脚注”区时，会创建二级“脚注”标题。
- 新文档首次插入使用 `[^编号]: 内容`，之后可以通过“统一格式”切换为有序列表。
- 新编号自动分配；插入操作可通过一次撤销恢复。

### 在侧栏编辑和查找

“脚注”面板管理当前主文档的脚注。切换主文档时，面板随之更新；在侧栏编辑不会切换管理对象。

![新版脚注侧栏：①跳转样式开关，②格式整理，③脚注列表与引用次数，④原块编辑，⑤被引段落定位](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/02-sidebar.png)

面板顶部显示当前文档，以下五个区域从上到下对应图中标注：

- **① 脚注跳转样式**：与顶部菜单的“脚注跳转”同步，切换后立即生效并记住设置。开启文本标记的跳转、预览和上标显示；关闭后移除插件添加的样式，静态块引仍保留思源原生跳转和预览。
- **② 格式整理**：分别选择“引用写法”和“定义格式”，按需要勾选“连续编号”，再点击“统一格式”。
- **③ 脚注列表**：编号和引用次数分列显示，下方展示内容摘要，以及“缺失定义”“编号重复”“未引用”状态；点击选中要编辑的脚注。
- **④ 脚注原块**：右侧显示“自动保存”或“只读”。选中脚注后直接编辑文档中的原内容，支持思源富文本，修改自动保存。使用显式定义时，请保留开头的 `[^编号]:`。
- **⑤ 被引段落**：标题旁显示引用该脚注的正文段落数；各项展示正文摘要、上级标题和同段落引用次数，点击即可定位正文。
- **定位脚注原块**：跳到文档中这条脚注的实际位置。
- **刷新脚注（↻）**：手动重新读取当前文档的脚注列表。

正文中指向当前文档脚注内容段落或列表项的块引，也会计入引用次数和被引段落。

尚未打开文档或文档没有脚注时，面板会显示对应提示；没有脚注时可按提示使用斜杠菜单开始添加。未选中脚注时，编辑区和被引段落会提示先选择脚注。

## 预览、跳转和返回正文

![文本标记的阅读流程：悬停预览、点击定位脚注、通过返回正文按钮回到原处](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/03-navigation.png)

开启“脚注跳转样式”后，正文中的文本脚注标记会显示为可点击的上标，悬停时预览脚注内容，点击时定位对应定义。文末尚未加载的长文也可直接预览和跳转，无须先滚动到最后。

鼠标可以从文本标记移入预览框。长脚注可滚动查看，也可拖动滚动条或选取文字；离开标记和预览框后，预览会延迟关闭。

通过文本标记跳到脚注后，右下角会出现“返回正文”按钮，点击回到刚才的引用位置。同一脚注被多次引用时，返回最近点击的那一处。

脚注块引使用思源原生预览和跳转交互。不同文档中的同名脚注分别匹配各自的定义。

## 统一格式和连续编号

打开“脚注”侧栏，在顶部选择目标格式，再点击“统一格式”。

| 设置 | 可选项与效果 |
| --- | --- |
| 引用 | **静态块引**：统一为指向脚注的 `[编号]` 块引；**文本标记**：统一为 `[^编号]`；**保留写法**：保留各处是块引还是文本标记，按需要更新编号。 |
| 定义 | **文末有序列表**：将脚注整理到文末列表中，去掉 `[^编号]:` 前缀；**`[^编号]: 内容`**：恢复前缀，将列表脚注转为定义段落。 |
| 连续编号 | 默认勾选：按正文首次引用顺序，从 1 开始连续编号；同一脚注多处引用共用编号，未引用的定义排在最后。取消勾选则保留现有编号。 |

默认组合为“静态块引 + 文末有序列表 + 连续编号”。确认框会显示影响范围、目标定义格式和编号变化，确认后执行全文整理，包括尚未加载的正文。

![统一格式前后对照：按正文首次引用顺序连续编号，多处引用共享编号，未引用定义排在末尾](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/04-normalize.png)

如图，乙先被引用，所以由 `[^8]` 变为 `[1]` 块引；甲随后被引用，变为 `[2]`。乙的第二处引用仍使用 `[1]`，未引用定义排在最后。

整理会保留脚注内容的加粗、链接等富文本，以及原内容块的引用关系；操作可通过一次撤销恢复。选择有序列表并取消“连续编号”时，现有编号必须是连续的正整数，否则请勾选“连续编号”。

### 列表调整后刷新序号

调整脚注列表的顺序、删除列表项或修改起始编号后，侧栏可能提示“序号已变化，请刷新序号”。点击“刷新序号”，确认后按当前脚注编号更新正文显示，保留引用目标和列表顺序。

![刷新序号前后对照：甲从列表第1项移到第2项，正文块引显示由1更新为2，引用目标与列表顺序不变](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/05-refresh.png)

如图，甲移到列表第二项后，正文块引仍指向甲，但显示编号需要由 `[1]` 更新为 `[2]`。“刷新序号”完成这一步，不会把甲重新移回第一项。

静态块引的显示编号不会随列表重排自动变化，因此列表调整后应检查此提示。希望按正文首次引用顺序重新排列、从 1 编号时，使用勾选“连续编号”的“统一格式”。

## 顶部菜单

点击顶部脚注按钮，可使用以下功能：

| 菜单项 | 用途 |
| --- | --- |
| 打开脚注侧栏 | 查看、编辑脚注和定位被引段落。 |
| 脚注跳转 | 开启或关闭文本标记的跳转、预览与上标显示。 |
| 编辑块实时刷新 | 开启时，正在编辑的块也会自动刷新脚注显示；关闭时，离开该块后再处理。中文输入期间会暂停刷新。 |
| 检查重复脚注编号 | 检查全文重复定义，并提供定位入口。 |
| 为脚注标记添加块引 | 将正文段落、标题和表格中的 `[^编号]` 转为静态块引，启用思源原生预览；缺失或重复定义的标记会跳过。执行前需要确认，可撤销。 |
| 转换脚注定义格式 | 打开侧栏，在“定义”中选择格式，再点击“统一格式”。 |

## 常见问题

**提示“缺失定义”怎么办？**

选中该项，点击“被引段落”定位正文，检查引用编号和对应脚注是否一致。使用有序列表时，还需检查列表是否位于文末，以及文档中是否残留 `[^编号]:` 定义。

**同一编号有多条定义怎么办？**

重复编号会显示红色双下划线，悬停提示冲突；点击文本标记可选择定义。也可从顶部菜单执行“检查重复脚注编号”逐一定位，手动修正后再整理。缺失定义或编号重复时，“统一格式”会要求先处理这些问题。

**提示内容已改变或有待保存的块怎么办？**

全文操作会自动结束表格中的编辑选区，并等待思源保存待处理输入后继续；表格仍使用完整保存内容，避免遗漏未加载的行。保存失败或旧版思源无法确认保存完成时，会提示重试。

![表格编辑后的整理流程：自动结束表格编辑，等待原生保存，读取完整文档后核对并确认；保存失败时停止并提示重试](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.9/assets/guide/06-save.png)

通常无须手动移出表格。若提示保存尚未完成，请等待当前编辑保存后重新执行；中文输入时请先完成输入法组合。确认格式整理或块引转换期间，若修改了内容或切换文档，需要重新检查并确认。

**旧版本转换后，块引找不到脚注怎么办？**

如果块引仍显示脚注编号，且该编号能明确对应当前文档的一条脚注，可再次执行“统一格式”修复空目标。缺失或重复编号时，请先修正定义。

**哪些操作会修改笔记？**

查看列表、预览和定位只读取文档。侧栏编辑会直接修改原脚注并自动保存；插入、块引转换、统一格式和刷新序号会修改笔记，支持思源撤销。只读文档支持查看和定位，不支持编辑或整理。

**哪些内容不会参与全文整理？**

代码、嵌入文档的内容、普通块引和跨文档块引不会作为当前文档的脚注参与整理。

## 安装与更新

将发布包 `package.zip` 解压到思源工作空间的 `data/plugins/siyuan-footnote-jumper/`，更新时覆盖原插件文件，保留插件设置。重启思源后，在插件设置中启用“脚注跳转”。当前版本为 **0.2.9**。

本版更新侧栏布局，新增与顶部菜单同步的“脚注跳转样式”开关，完善空状态与只读提示；全文整理和块引转换会自动结束表格编辑并等待保存。同时包含内容变化误报、编辑器同步、引用目标丢失及撤销重做的修复。新生成的静态块引显示为 `[编号]`，旧的 `[^编号]` 块引继续兼容。
