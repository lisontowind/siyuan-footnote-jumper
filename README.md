# 脚注跳转

[English](README_en_US.md) | 简体中文

在思源笔记中插入、预览和管理脚注：正文点击跳转，侧栏直接编辑脚注内容，查看被引段落，还能统一引用写法、切换文末格式和重新编号。

## 快速开始

![新版插入弹窗：搜索复用已有脚注，或填写新内容并点击新建脚注](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/01-insert.png)

1. 启用插件，打开需要添加脚注的文档。
2. 在正文段落或标题中输入 `/`，搜索“脚注”“footnote”或“jz”，选择“插入脚注”。
3. 在弹窗中输入编号或内容搜索已有脚注，或填写新内容后点击“新建脚注”自动分配编号。引用按侧栏偏好插入，默认使用原生上标静态块引 `[^编号]`。
4. 新建时会在文末保存填写的内容并聚焦侧栏编辑区；也可留空新建，后续编辑自动保存到原文档。复用已有脚注不会重复创建定义。
5. 悬停正文引用可预览内容；文本标记可点击跳到定义，块引沿用思源原生交互。

已有脚注的文档可直接使用，无须重新插入。从右侧停靠栏打开“脚注”面板。插件仅保留侧栏入口，不再添加顶部图标。

## 支持哪些脚注写法

正文引用支持两种写法：

| 写法 | 如何使用 |
| --- | --- |
| 文本标记 `[^1]` | 直接在正文输入，插件提供上标显示、预览和点击跳转。 |
| 静态块引 `[^1]` / `[1]` | 由“插入脚注”或格式转换生成，默认显示 `[^1]`，指向对应脚注，使用思源原生悬浮预览。 |

块引的显示文字可通过“统一格式”在 `[^1]` 和 `[1]` 之间切换。**只输入普通文本 `[1]` 不会创建脚注引用**。

脚注内容支持以下两种格式。静态块引可选择任一种，文本标记固定使用 `[^编号]: 内容`。

### 格式一：`[^编号]: 内容`

在正文写引用，在脚注定义段落开头写相同编号：

```markdown
这段文字需要补充说明 [^1]。
另一段文字也可以引用同一条脚注 [^1]。

## 脚注

[^1]: 这里是脚注内容，可以包含加粗、链接等格式。
```

### 格式二：文末有序列表

将脚注内容写在文档最后的有序列表中，引用编号对应列表实际显示的序号：

```markdown
第一处说明 [^1]，第二处说明 [^2]。

## 脚注

1. 第一条脚注内容。
2. 第二条脚注内容。
```

插件只将文档末尾的顶层有序列表识别为脚注区，末尾空段落不影响识别。列表后若还有其他正文，就不再是文末脚注列表；正文中的其他列表不会被当作脚注。列表可以从其他正整数开始，按实际序号匹配。

**同一文档请选择一种定义格式。** 文档中存在 `[^编号]: 内容` 时，插件优先使用这种格式；只有没有此类定义时，才读取文末有序列表。

## 插入和编辑脚注

### 斜杠菜单插入

在正文段落或标题中使用 `/` → “插入脚注”，弹窗支持按编号或完整内容搜索已有脚注，编号可输入 `12`、`[^12]` 或 `[12]`。使用上下键或点击列表项选中，再点击“插入脚注”确认；搜索框按 Enter 只将焦点移到确认按钮。重复编号和缺失定义会显示原因，不能复用；Esc 或“取消”关闭弹窗并恢复原来的斜杠选区，不修改笔记。

候选列表首次渲染 40 条，滚动接近边缘时自动加载相邻批次，已有行和当前选择保持不变。搜索与计数覆盖当前文档全部脚注；上下键可以跨批次选择并自动显示目标，搜索变化后从首批重新显示。关闭弹窗后停止滚动加载。

需要新建时，选择“新建一条脚注”，展开“新脚注内容”输入区，确认按钮切换为“新建脚注”；填写内容或留空后点击按钮创建，编号自动分配，内容作为纯文本保存。切换回已有脚注时，确认按钮恢复为“插入脚注”，新建草稿保留。搜索没有匹配时自动进入新建模式；搜索文字不会自动写入脚注。选择、输入和切换模式均不会修改笔记，点击确认按钮后才提交。

- 已有文末有序列表脚注时，在列表末尾追加一项。
- 使用 `[^编号]: 内容` 时，在文末追加定义及填写的内容；没有文末“脚注”区时，会创建二级“脚注”标题。
- 无脚注文档按侧栏偏好创建定义区：静态块引默认使用文末有序列表；文本标记使用 `[^编号]: 内容`。已有文档沿用其定义格式，格式不符时在侧栏提示整理。
- 新编号自动分配，计入正在原生保存队列中的脚注；插入操作可通过一次撤销恢复。
- 弹窗和插入不等待全文保存，不受无关块的保存状态影响。插入仅更新来源块并追加必要定义或列表项，不重写整个脚注列表；来源或目标已改变时会提示重新执行。

### 在侧栏编辑和查找

侧栏分为“脚注”和“设置”两个面板。“脚注”面板集中显示编号定位、脚注列表、原块编辑器和被引段落；“设置”面板集中显示引用写法、格式整理、格式检查和重复编号检查。两个面板独立滚动，切换时保留所选脚注与编辑状态，设置面板打开期间暂停脚注列表增量渲染。脚注列表首次加载 40 项，被引段落首次加载 30 项，上下滚动接近列表边缘时自动加载相邻批次，无需点击加载按钮；计数和全文格式检查始终覆盖完整文档。刷新会复用未变化的列表项，保留当前滚动位置与原块编辑器。切换主文档时，面板随之更新；在侧栏编辑不会切换管理对象。

![脚注面板：按编号定位、脚注列表与引用次数、原块编辑和被引段落](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/02-sidebar.png)

面板顶部显示当前文档。“脚注”面板用于查找、编辑与定位；“设置”面板用于保存偏好、整理格式和检查问题。

右上角提供独立的「自动刷新」开关和刷新按钮，在两个面板和两种引用写法下均可使用。自动刷新默认开启，只在侧栏打开时，随当前文档的编辑与同步延迟更新列表、引用次数和格式提示；关闭侧栏后停止面板的自动全文读取。每次打开侧栏或侧栏可见时切换文档，都会读取一次当前文档。长文档可关闭「自动刷新」，之后按需点击右上角刷新按钮；开关会保存，重新开启时立即刷新一次。刷新按钮同时更新正文文本标记，刷新期间暂不可重复点击，中文输入法组合期间延后处理。

正文文本标记的跳转和悬停预览独立工作，仍可按需查询尚未加载的脚注，不受面板开关影响。

- **脚注列表**：编号和引用次数分列显示，下方展示内容摘要，以及“缺失定义”“编号重复”“未引用”状态；点击选中要编辑的脚注。
- **脚注原块**：右侧显示“自动保存”或“只读”。选中脚注后直接编辑文档中的原内容，支持思源富文本，修改自动保存。使用显式定义时，请保留开头的 `[^编号]:`。
- **被引段落**：标题旁显示引用该脚注的正文段落数；各项展示正文摘要、上级标题和同段落引用次数，点击即可定位正文。
- **定位脚注原块**：跳到文档中这条脚注的实际位置。
- **按编号定位**：在脚注列表上方输入编号，按 Enter 或点击“定位”，即可选中并显示对应脚注和被引段落。支持 `12`、`[^12]`、`[12]`，也支持已有的字母编号；未加载的条目会直接加载其所在批次并滚动显示，无须多次点击；上下滚动即可自动加载相邻条目，向上加载会保持当前可见位置。同一编号对应多条定义时，再次定位可逐条切换；没有匹配项时会提示。
正文中指向当前文档脚注内容段落或列表项的块引，也会计入引用次数和被引段落。

尚未打开文档或文档没有脚注时，面板会显示对应提示；没有脚注时可按提示使用斜杠菜单开始添加。未选中脚注时，编辑区和被引段落会提示先选择脚注。

### 在“设置”面板保存偏好与检查格式

![设置面板：引用写法、定义格式、块引编号、连续编号、原生上标、统一格式和文档检查](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/07-settings.png)

- **引用写法**：会记住选择并控制后续插入；切换偏好后，已有内容需点击“统一格式”并确认才转换。
- **格式整理**：静态块引可选择“定义格式”和“块引编号”，再按需要勾选“连续编号”“引用使用上标”。文本标记固定使用显式定义。
- **文本标记选项**：仅选择“文本标记”时显示“脚注跳转样式”和“编辑块实时刷新”。跳转样式提供匹配、跳转、预览与临时上标；关闭后保留已保存的原生上标。编辑块实时刷新默认开启，只控制正文标记匹配；关闭后在离开编辑块时自动匹配，也可点击右上角刷新按钮立即匹配。它与面板的「自动刷新」开关互相独立。中文输入法组合期间延后处理。
- **格式检查**：读取面板数据时检查当前文档与全部格式偏好是否一致，列出不符项并提示“统一格式”，不会自动改写或反复弹窗。侧栏关闭时不自动读取全文或检查格式。
- **检查重复脚注编号**：查看冲突定义并定位处理。

## 预览、跳转和返回正文

![文本标记的阅读流程：悬停预览、点击定位脚注、通过返回正文按钮回到原处](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/03-navigation.png)

开启“脚注跳转样式”后，正文中的文本脚注标记会显示为可点击的上标，悬停时预览脚注内容，点击时定位对应定义。文末尚未加载的长文也可直接预览和跳转，无须先滚动到最后。

鼠标可以从文本标记移入预览框。长脚注可滚动查看，也可拖动滚动条或选取文字；离开标记和预览框后，预览会延迟关闭。

通过文本标记跳到脚注后，右下角会出现“返回正文”按钮，点击回到刚才的引用位置。同一脚注被多次引用时，返回最近点击的那一处。

脚注块引使用思源原生预览和跳转交互。不同文档中的同名脚注分别匹配各自的定义。

## 统一格式和连续编号

打开“脚注”侧栏，切换到“设置”面板，选择目标格式，再点击“统一格式”。

| 设置 | 可选项与效果 |
| --- | --- |
| 引用 | **静态块引**：统一为指向脚注的块引；**文本标记**：统一为 `[^编号]`，脚注定义固定使用 `[^编号]: 内容`。 |
| 块引编号 | 选择静态块引后显示。默认 `[^编号]`，可切换为 `[编号]`；仅影响静态块引的显示文字。 |
| 引用使用上标 | 默认勾选，两种引用写法均保存为思源原生上标；取消勾选时保留已有上标及行内样式。文末定义保持正常大小。 |
| 定义 | 选择静态块引后显示。**文末有序列表**：将脚注整理到文末列表中，去掉 `[^编号]:` 前缀；**`[^编号]: 内容`**：恢复前缀，将列表脚注转为定义段落。 |
| 连续编号 | 默认勾选：按正文首次引用顺序，从 1 开始连续编号；同一脚注多处引用共用编号，未引用的定义排在最后。取消勾选则保留现有编号。 |

默认组合为“静态块引 + 文末有序列表 + 连续编号 + 引用使用上标”。确认框会显示影响范围、目标定义格式和编号变化，确认后执行全文整理，包括尚未加载的正文。

选择静态块引时使用思源原生交互，隐藏文本匹配选项；切换为文本标记时，“块引编号”和“定义格式”自动隐藏，显示跳转与刷新选项；已有列表脚注会在确认整理后转成固定编号定义，避免列表自动编号影响文本引用。切回静态块引时恢复显示，并保留此前选择。旧的“文本标记 + 有序列表”文档仍可读取；刷新序号时也会迁移为固定编号定义。

格式转换兼容引用中的加粗、斜体、颜色等行内样式。已经使用原生上标的标记不会再次叠加插件的缩小、抬高样式，文本标记仍可跳转和预览；关闭“脚注跳转样式”也会保留已保存的原生上标。

![统一格式前后对照：按正文首次引用顺序连续编号，多处引用共享编号，未引用定义排在末尾](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/04-normalize.png)

如图，乙先被引用，所以由 `[^8]` 变为 `[^1]` 块引；甲随后被引用，变为 `[^2]`。乙的第二处引用仍使用 `[^1]`，未引用定义排在最后。

整理会保留脚注内容的加粗、链接等富文本，以及原内容块的引用关系；操作可通过一次撤销恢复。选择有序列表并取消“连续编号”时，现有编号必须是连续的正整数，否则请勾选“连续编号”。

### 列表调整后刷新序号

调整脚注列表的顺序、删除列表项或修改起始编号后，侧栏“设置”面板可能提示“序号已变化，请刷新序号”。点击“刷新序号”，确认后按当前脚注编号更新正文显示，保留引用目标和列表顺序。

![刷新序号前后对照：甲从列表第1项移到第2项，正文块引显示由1更新为2，引用目标与列表顺序不变](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/05-refresh.png)

如图，甲移到列表第二项后，正文块引仍指向甲，但显示编号需要由 `[^1]` 更新为 `[^2]`。“刷新序号”完成这一步，不会把甲重新移回第一项。

静态块引的显示编号不会随列表重排自动变化，因此列表调整后应检查此提示。希望按正文首次引用顺序重新排列、从 1 编号时，使用勾选“连续编号”的“统一格式”。

## 偏好与格式提示

引用写法、定义格式、块引编号、连续编号、上标、面板自动刷新，以及文本模式的跳转和编辑块实时刷新开关均会保存。切换引用写法时保留此前各项选择。

面板格式检查只读取当前文档，覆盖未加载正文，忽略插件临时样式；尚有未保存的结构变化时暂不报告格式问题。自动刷新开启时，待内容稳定后重新检查；关闭时可手动刷新。侧栏会提示具体不符项，点击已有“统一格式”按钮并确认后才修改笔记。

取消“引用使用上标”表示不强制新增上标，已有上标不会视为格式错误，也不会被移除。将文本标记转换为静态块引统一使用“引用写法 → 静态块引 → 统一格式”。

## 常见问题

**提示“缺失定义”怎么办？**

选中该项，点击“被引段落”定位正文，检查引用编号和对应脚注是否一致。使用有序列表时，还需检查列表是否位于文末，以及文档中是否残留 `[^编号]:` 定义。

**同一编号有多条定义怎么办？**

重复编号会显示红色双下划线，悬停提示冲突；点击文本标记可选择定义。也可从侧栏执行“检查重复脚注编号”逐一定位，手动修正后再整理。缺失定义或编号重复时，“统一格式”会要求先处理这些问题。

**提示内容已改变或有待保存的块怎么办？**

全文格式整理会自动结束表格中的编辑选区，并等待思源保存待处理输入后继续；表格仍使用完整保存内容，避免遗漏未加载的行。保存失败或旧版思源无法确认保存完成时，会提示重试。

![表格编辑后的整理流程：自动结束表格编辑，等待原生保存，读取完整文档后核对并确认；保存失败时停止并提示重试](https://raw.githubusercontent.com/lisontowind/siyuan-footnote-jumper/v0.2.11/assets/guide/06-save.png)

斜杠插入使用局部事务，无关块的待保存状态不会阻塞弹窗与插入。全文整理通常无须手动移出表格。若提示保存尚未完成，请等待当前编辑保存后重新执行；中文输入时请先完成输入法组合。确认格式整理或块引转换期间，若修改了内容或切换文档，需要重新检查并确认。

**旧版本转换后，块引找不到脚注怎么办？**

如果块引仍显示脚注编号，且该编号能明确对应当前文档的一条脚注，可再次执行“统一格式”修复空目标。缺失或重复编号时，请先修正定义。

**哪些操作会修改笔记？**

查看列表、预览和定位只读取文档。侧栏编辑会直接修改原脚注并自动保存；插入、块引转换、统一格式和刷新序号会修改笔记，支持思源撤销。只读文档支持查看和定位，不支持编辑或整理。

**哪些内容不会参与全文整理？**

代码、嵌入文档的内容、普通块引和跨文档块引不会作为当前文档的脚注参与整理。

## 安装与更新

将发布包 `package.zip` 解压到思源工作空间的 `data/plugins/siyuan-footnote-jumper/`，更新时覆盖原插件文件，保留插件设置。重启思源后，在插件设置中启用“脚注跳转”。当前版本为 **0.2.11**。

本版新增独立的面板自动刷新开关和通用刷新按钮，关闭侧栏后停止面板全文读取；修复工具栏按钮显示和开关对齐。同步提供完整英文说明与七张英文配图，中英文说明可在顶部切换。

图文教程包含插入弹窗、脚注面板、设置面板、预览跳转、统一格式、刷新序号和表格保存流程七张配图，图片使用对应发布版本的 GitHub 公开链接，查看需要联网。
