# 脚注跳转

这是一个思源笔记插件，为 Markdown 风格脚注提供点击跳转、预览、侧栏原块编辑、引用段落定位和全文格式整理。

支持的写法：

```markdown
正文里引用脚注 [^1]。

[^1]: 这里是脚注内容。
```

也兼容文末的有序列表（只识别最后一个顶层有序列表，忽略尾部空段落）：

```markdown
正文里引用脚注 [^1]。

1. 这里是脚注内容。
2. 另一条脚注内容。
```

两种定义格式互斥识别：全文存在 `[^编号]: 内容` 时优先使用显式定义；没有显式定义时才读取末尾有序列表。列表按实际显示顺序和起始编号匹配脚注，不把正文中的其他列表当作定义。

启用后：

- 右侧停靠栏新增“脚注”面板，也可从顶部脚注按钮选择“打开脚注侧栏”。面板管理当前主文档，列出脚注摘要、引用次数、重复编号、缺失定义和未引用状态。
- 选中脚注可在侧栏的思源原生编辑器中编辑原定义块，保留富文本并自动保存。编辑区包含 `[^编号]:` 前缀，正文内容可直接修改；重复编号需要先手动修复。
- “被引段落”显示正文摘要、最近的上级标题和同段落引用次数；点击可定位到正文，即使正文尚未加载。侧栏获得焦点不会切换管理文档，刷新列表不会重建正在编辑的同一个脚注。
- 文本标记和指向当前文档脚注定义的块引共用上标样式；块引继续使用思源原生预览。普通块引、跨文档块引、代码和嵌入文档不进入格式整理。
- 正文中锚文本为 `[数字]` 的脚注块引也计入引用次数和被引段落，并参与统一格式；指向脚注内容段落或文末有序列表项均可识别。识别按目标块 ID 匹配，整理时按目标脚注编号更新；切回显式定义时会将列表项块引转向保留的内容段落。
- 插入脚注、转换为静态块引和统一格式时，静态块引显示为 `[编号]`；文本标记仍使用 `[^编号]`，显式定义仍使用 `[^编号]: 内容`。已有 `[^编号]` 块引继续兼容，可通过统一格式改为 `[编号]`。
- 侧栏“统一格式”的“定义”选项可二选一：文末有序列表（默认）或 `[^编号]: 内容`。引用写法独立选择静态块引、文本标记或保留写法。默认按正文首次引用顺序从 1 连续编号，同一脚注多处引用共享编号，未引用定义排在末尾；列表模式取消连续编号时，原编号必须是连续的正整数。
- 全文整理保留定义内容块 ID 和富文本，有序列表模式将定义移到文末并去除 `[^编号]:` 前缀；切回显式定义时恢复前缀并展开列表项。确认前显示影响数量、目标格式和编号变化，确认后重新核对全文。重复编号、缺失定义、待保存新块、文档切换、中文输入期间或表格待保存时停止提交，提交后可一次撤销恢复。
- 列表重排、删除或修改起始编号后，侧栏提示“序号已变化，请刷新序号”，可点击“刷新序号”按当前定义编号更新正文，保留原引用目标和列表顺序。插件转换的定义记录上一次编号，文本标记在刷新前继续匹配原脚注；首次导入的列表在侧栏本次会话内记录编号。静态块引始终按块 ID 匹配。思源动态锚文本跟随目标块内容，不能直接用来只显示自动变化的脚注序号。
- 输入 `/` 后搜索“脚注”“footnote”或“jz”，选择“插入脚注”：正文插入静态块引，并沿用当前定义格式，列表模式追加空列表项，显式定义模式在文末“脚注”区追加空定义并在侧栏选中。没有末尾脚注区时新建二级“脚注”标题；新编号避开已有定义及未解析的文本引用。标记、定义和新标题可一次撤销。
- 只读文档可查看和定位脚注，不能编辑、插入或统一格式。关闭面板时释放原块编辑器，再打开时恢复选择。
- 顶部栏会出现脚注按钮，点击后可在菜单中启用或停用插件。
- 菜单中的“编辑块实时刷新”可控制当前编辑块是否自动刷新；关闭后会在光标离开该块时处理。
- 菜单中的“为脚注标记添加块引”会读取全文，在用户确认后，将正文段落、标题和表格中的脚注标记转换为指向脚注定义块的静态块引用，包括尚未加载的正文，从而启用思源原生的悬浮预览；该操作会修改笔记内容，但可使用撤销恢复。缺失定义或重复编号的标记会跳过。
- 同一文档中编号重复的脚注会显示红色双下划线，悬浮时提示冲突；点击标记可以选择需要定位的定义。顶部菜单中的“检查重复脚注编号”会检查全文并列出定位入口。
- 全文转换会在确认后重新核对正文和转换目标，内容发生变化时要求重新执行；正在编辑或等待刷新的表格会阻止全文操作。嵌入文档的内容不会进入当前文档的定义索引或转换事务。
- `[^1]` 会临时显示为可点击引用。
- 标记中的编号带有加粗、斜体等格式时也可识别；临时增强保留原有富文本，代码、表格单元格和换行之间不会拼接成脚注标记。
- 鼠标悬停引用时显示脚注内容预览。
- 鼠标可从脚注标记移入预览框，长脚注支持滚轮滚动、拖动滚动条和选取文字；离开标记和预览框后会延迟关闭。
- 点击引用会自动滚动到文档末尾对应的 `[^1]: ...` 定义。
- 跳到脚注定义后，右下角会出现“返回正文”按钮，点击可回到刚才点击的引用；原正文块尚未加载时会通过思源加载并定位。同一脚注多次引用时，返回最近点击的那一处。
- 长文中的脚注定义会按文档从思源内核读取，末尾尚未加载时也可预览；点击会通过思源加载并定位目标块。滚动后动态加载的正文会继续自动处理。
- 脚注编号只在所在文档内匹配，多个打开文档中的同名脚注不会互相串用。
- 脚注列表、跳转和悬浮预览只读取文档；原块编辑、斜杠插入、确认后的块引转换和格式整理会修改笔记内容，并支持撤销。
- 插件使用块级增量刷新，并在中文输入期间暂停处理，避免频繁更新干扰编辑。

## 长文脚注的读取方式

插件通过思源内核 `/api/query/sql`，按引用所在文档的 `rootID` 查询脚注定义的内容和块 ID，不要求先滚动到文末。查询按块 ID 稳定排序，每页最多 256 个候选块，直到读完结果；不会受思源默认搜索结果条数限制。

查询结果按文档缓存 30 秒，同一文档的并发请求会合并。可识别的编辑事务只刷新受影响的文档：普通正文更新保留脚注缓存，定义变更、插入或删除会使该文档的缓存失效；刷新、同步以及无法识别来源的事务保留全局失效处理。编辑后立即查询得到的结果会在延迟刷新时重新读取，避免思源异步 SQL 索引的旧内容被长期缓存。已加载块的最新内容优先于 SQL 查询结果。重复定义会保留全部候选块，不会随着正文加载范围变化而静默切换目标。

全文转换和重复编号检查通过 `/api/block/getBlockDOM` 读取完整文档，转换生成的正向和撤销事务均清除插件临时标记。表格使用内核返回的完整内容，避免只保存编辑器当前加载的行。

## 安装更新与长文验证

1. 解压 `package.zip`，将其中的文件覆盖到思源工作空间的 `data/plugins/siyuan-footnote-jumper/` 目录，保留插件设置。
2. 重启思源，确认插件版本为 `0.2.4` 并开启“脚注跳转”。
3. 打开一篇文末包含 `[^1]: 内容` 的长文，在尚未滚动到文末时悬浮正文的 `[^1]`：应显示脚注内容；点击应加载并高亮文末定义块。
4. 检查两个文档中的同名脚注分别显示各自内容；修改、重命名或删除定义后，等待刷新再检查预览及跳转。
5. 滚动加载新正文块，检查脚注继续生效；使用中文输入法编辑，检查输入期间不会被插件刷新打断。
6. 悬浮一个超过预览框高度的长脚注，将鼠标移入框内，使用滚轮或拖动滚动条查看末尾内容；移回脚注标记时预览保持，移到其他区域后关闭。
7. 点击正文脚注跳到文末后，点击右下角“返回正文”按钮，检查回到刚才点击的位置；正文已卸载或已切换文档时也能返回原正文块。
8. 在长文中执行“为脚注标记添加块引”，确认尚未加载的正文也转换；撤销后标记应恢复。确认框打开后修改正文或切换文档，应停止提交并提示重新执行。
9. 添加两个同编号定义，检查冲突提示和“检查重复脚注编号”的定位入口；修改其中一个编号后，原编号应恢复唯一匹配，块引转换应跳过仍然重复的编号。
10. 同时打开多个文档，编辑普通正文，检查其他文档的脚注继续使用缓存；编辑定义后检查该文档的预览更新。
11. 打开“脚注”侧栏，在原块编辑器修改加粗、链接或块引，检查主文档同步、原生撤销和引用列表刷新；切换文档及关闭再打开侧栏，检查列表和编辑器对应正确。
12. 混合文本标记与块引，按不同顺序引用旧编号，执行“统一格式”；检查首次引用顺序、未引用脚注排在末尾、定义块 ID 和格式保留，以及一次撤销。重复编号或缺失定义时应显示定位入口并阻止整理。
13. 在正文中用斜杠菜单插入脚注，检查命令替换位置、末尾脚注区、自动选中新定义和一次撤销；异步读取期间移动光标、修改正文或切换文档，应停止插入。
14. 选择“文末有序列表”并统一格式，检查定义前缀移除、原块 ID 和富文本保留；切回 `[^编号]: 内容`，检查前缀恢复与一次撤销。
15. 调整列表项顺序或起始编号，检查侧栏提示“序号已变化，请刷新序号”；刷新后正文编号对应新列表顺序，块引目标和列表顺序保持。列表模式插入脚注应追加列表项。

自动化回归测试使用模拟的思源宿主，并通过 LinkeDOM 检查 DOM、文档顺序、混合脚注索引、整理与插入事务、侧栏生命周期和异步切换。真实浏览器检查使用 Chromium 和模拟的思源原块编辑器，验证 Range、光标变化、面板显隐、移动端布局和交互；实际思源内核事务、原生编辑与长文定位仍需安装后验证。

显式定义按当前 `[^编号]:` 前缀匹配，手动改编号不受历史列表编号属性影响。全文操作会检查已加载列表的类型、编号和块归属是否已保存；侧栏原块编辑不改变列表归属。格式整理仅清理本次转换涉及的空列表容器。侧栏忽略明确属于其他文档的编辑事务和加载事件，同步或无法识别文档的事件仍触发刷新；长文整理使用块 ID 索引生成正向与撤销事务，减少重复扫描。

`0.2.1` 修复思源 v3.8.7 插入脚注时的 `Cannot read properties of undefined (reading 'NewNodeID')`：通过思源提供的全局 `window.Lute` 生成块 ID，并在生成器未就绪时停止提交。回归宿主模拟已改为实际接口形态，不再假设 `siyuan` 模块导出 `Lute`。

`0.2.2` 修复斜杠插入后正文标识未显示的问题：思源事务会跳过当前光标所在块的界面更新，插件现先更新本地正文、放置光标，再提交同一个可撤销事务，并更新后续编辑使用的撤销基线。正文位于文末时同时更新可见脚注区；真实文末尚未加载时保留原插入位置，交由内核加载。浏览器回归还原宿主跳过当前编辑块的行为，检查标识即时显示、撤销重做和同步提交失败后的恢复。

## 开发

`0.2.4` 将插入和统一格式生成的静态块引显示为 `[编号]`，兼容已有 `[^编号]` 块引；文本标记和显式定义保持 Markdown 写法。正文指向脚注段落或列表项的 `[数字]` 块引参与引用统计与统一格式。修复显式定义改名后误报缺失、待保存列表识别、跨富文本节点标记识别和无关空列表清理，并减少其他文档触发的侧栏刷新与长文重复扫描。详见 [更新记录](CHANGELOG.md)。

`0.2.3` 增加文末有序列表兼容，定义格式可在有序列表与 `[^编号]: 内容` 间二选一转换，并增加序号变化提示和刷新序号操作。格式转换保留原内容块 ID、富文本与撤销事务，列表模式插入脚注沿用列表格式。

```bash
npm install
npm run dev
```

开发模式会生成 `index.js` 和 `index.css`。

## 打包

```bash
npm run build
```

打包结果位于 `dist/`，同时生成 `package.zip`。

回归检查：

```bash
npm test
npx tsc --noEmit
```

可选浏览器检查（使用已安装的 Playwright 和 Chromium，不自动下载依赖）：

```bash
npm run test:browser
```

已有外部 Playwright 包时可设置 `FOOTNOTE_PLAYWRIGHT` 为其绝对路径；已有 Chromium/Edge 时可设置 `FOOTNOTE_BROWSER_EXECUTABLE` 为浏览器可执行文件路径。Windows 外部运行时如遇 Node 路径解析权限问题，可用 `node --preserve-symlinks scripts/verify-browser.cjs`。检查截图默认保存在 `dist/browser-check/`，可通过 `FOOTNOTE_BROWSER_ARTIFACTS` 指定其他位置。
